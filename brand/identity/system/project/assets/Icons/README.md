# Icons

A rounded line set: 24 × 24 grid, 2px stroke, round caps and joins. The files are drawn in `space` (#12133A). In code, use `Bhoogol.icon(name)` so the icon follows `currentColor`.

The set: globe, quiz, compare, layers, search, wildlife, tour, play, river, mountain, ocean, capital, mark, star, sound, settings, share.
